## Headline: P0 #27, nothing is ever veiled
`veil.js` calls `window.stop()` then `document.open(); document.write(html); document.close()` at document_start. In Chromium that leaves **no `<body>`**, so `document.getElementById('rel')` is null and the script throws `Cannot set properties of null (setting 'onclick')`. Same on youtube.com, example.com, wikipedia.org, tiktok.com, headless and headed. Everything after the throw never runs: no `VEIL_UP` (the app tab is never opened or poked, so the sonar does not autostart), no `storage.onChanged` listener (PROGRESS dots never show, UNLOCK does not reload the tab). The user sees a blank white page.

**Fix, verified in a scratch copy (not applied):** in `paint()` replace the `document.open/write/close` line with
`const d = new DOMParser().parseFromString(html, 'text/html'); document.documentElement.replaceWith(document.importNode(d.documentElement, true))`.
With it the fake page renders with title = hostname, `#dots` exists, no page errors. Please also try it by hand in branded Chrome: Chrome 137+ ignores `--load-extension`, so I could only test Chromium.
